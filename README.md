# PARAM
This is a late-stage snapshot of the development environment that was used by James ("Jimmy") J. P. Stewart to develop the PMx family of semiempirical models.
PARAM itself is incorporated into the open-source MOPAC distribution, so this repo is not necessary for using PARAM. However, the documentation of PARAM is limited, and this repo might contain useful information for anyone attempting to fit new MNDO-form semiempirical models using PARAM. This snapshot is from a Windows development environment that included Microsoft Visual Studio and the Intel Fortran compiler.
