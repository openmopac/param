Migration to MOPAC

Parameters optimized using PARAM can be migrated for use in MOPAC.  The simplest mechanism is to use the MOPAC keyword EXTERNAL to read in the optimized values from a file.  This would allow the full range of functionality of MOPAC to be used with the new method.

Eventually, there will be a need to make a permanent change to MOPAC, to allow the new method to be fully integrated into the program.  This can be done using the keyword, DEP.
