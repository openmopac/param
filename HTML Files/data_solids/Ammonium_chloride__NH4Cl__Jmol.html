Ammonium chloride is mechanically very weak. This is a consequence of the
intermolecular interactions - they are purely ionic. Because the interactions
are so small, a very large unit cell is needed in order to allow the cubic
lattice to be accurately modeled. If only three unit cels in each direction are
used, the system distorts significantly.
