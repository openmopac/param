Introduction to the structure PARAM

Program PARAM was originally designed to be used on its own for optimizing parameters in semiempirical methods.  Although it does this very well, there are many other tasks in method development that program PARAM cannot do.  These tasks can be performed inside the structure PARAM. 

The folder structure within PARAM has been made deliberately rigid.  This structure allows operations that involve different folders to be carried out easily.  Unless there is a compelling reason to alter this structure, do not make any changes to the names or locations of existing top-level folders, however sub-folders can be added and deleted as necessary. PARAM folders are based on a hierarchical structure with the top level consisting of the following folders:

Top level folders

Analysis

Surveys various sets of systems.  A typical survey would refer to various existing semiempirical methods, such as PM7, PM6, PM6-D3H4, etc., and a set of chemical systems, e.g., all compounds containing the elements H, C, N, O, F, P, S, Cl, Br, and I,  only, and sets of compounds involving intermolecular interactions, most of these being from Hobza's on-line repository.

Documentation

Descriptions of the structure of PARAM, its files, programs, techniques for various procedures, etc., are stored here.  All documentation is in HTML format, and it designed for quick access from.

HTML Files

This contains tables of the accuracies of prediction of different properties for various methods and displays of reference data systems.  The accuracy tables can be re-generated easily and re-generating the reference data systems takes only a few minutes, so if there is any question about the files, simply deleting all the files in this folder, followed by re-generating them is straightforward.

PARAM Manual

The original PARAM manual was intended to provide a description of what PARAM does.  It's now a bit dated, but is still useful as a source of definitions and descriptions of keywords and functions.  This can be contrasted with the documentation here which describes how to carry out various operations.

Parameter optimization

All parameter optimizations should be carried out in sub-folders within this folder.  If the PARAM structure is used the transfer of information between various optimization jobs can be done easily.

Reference data

The repository of all reference data used in parameterization.

Sandbox

Several sandboxes exist in PARAM.  These folder can be used for quick tests of data-sets and for testing ideas.
