Top Copies of Files

Both programs, MOPAC and PARAM, run on Windows, Mac, and Linux systems.  Running on more than one system causes problems regarding which files are the top copy.  For example, if a source-code file in PARAM on a Linux system is edited, and the modified file is an improvement, what should be done to propagate the change to other platforms?  Put another way, file maintenance is an issue that must be addressed.

The recommended approach to file maintenance is to have all top-copy files on the Windows platform.  This involves source code, compilation files such as Visual Studio and Makefiles, reference data files, and optimized parameter files. Large jobs - jobs taking several hours to a few weeks - should not be run on the Windows platform.  Almost always the first attempt to run a large job will fail because of faults in the input data, for this reason preliminary testing of large jobs should be done on the Windows platform, in one of the Sandbox folders where faults in the datasets can easily be identified and corrected

The other platforms, Mac and Linux, would then be used as pure compute engines.  Some utility files are available to help in setting up the Mac and Linux systems.
