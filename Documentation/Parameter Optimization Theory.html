Parameter optimization theory

A good introduction to the original optimization technique is given in "Stewart JJP. Optimization of Parameters for Semiempirical Methods I. Method. J Comp Chem. 1989;10(2):209-20" A public-domain copy of this article is available, in summary:

The optimization method used in PARAM starts by using a set of parameter values, and calculating the errors and the first derivatives of the errors with respect to each parameter using a semiempirical method, e.g., PM6-D3H4. These derivatives are then used in calculating the derivative of the error function.  The error function is then minimized by adjusting the parameters so as to reduce the error function.  This adjustment uses the derivatives and individual errors only, it does not involve any semiempirical calculations.  At the minimum, about 2000 optimization steps later, the errors and gradients are re-calculated  using the updated semiempirical method.  The parameters are again optimized using the derivatives and individual errors only.  This process is repeated until a stable set of parameters is obtained.

A bias function applied to motion of the parameters from their semiempirical starting point prevents runaway excursions in parameter space.  Runaway excursions are caused by the presence of almost-zero eigenvalues in the parameter Hessian.  This bias function is increased if the cosine of the angle between the gradient vector (the derivative) for the error function between the cycles (n-1) and (n) is significantly less than 1.0, and decreased as the cosine approaches 1.0. Put another way, if the direction of motion through parameter space is more-or-less the same as on the last cycle, the confidence level, i.e., the step-size, is increased, and decreased if the direction of motion starts to become erratic. 

After the original technique was published, several changes were made, the most important of these being that the use of analytical derivatives was abandoned in favor of finite difference derivatives.  Finite difference derivatives are very robust compared to analytic derivatives, and have the added serendipitous benefit of being much faster!
