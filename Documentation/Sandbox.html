Folder "Sandbox"

All folders that have the name "Sandbox" should be used only for testing ideas, and, with the single exception of the file Sandbox.html the contents, if any, of sandbox folders should be regarded as unimportant, i.e., they can be deleted without checking. Ideally, work in a sandbox should be completed in one session or one day and should not be allowed to continue over several days.

Uses of Sandbox folders

(A) Work on reference data and other MOPAC-type input files.  As soon as an acceptable file is made, it should be moved to another folder, e.g., to a folder in "PARAM\reference data".

(B) Work on making a valid parameter optimization data set for use with PARAM.  A good practice is to define quantities used in PARAM data sets by keywords REF=<text> and SET=<text>. The sandbox in "PARAM\Parameter Optimization" is ideally positioned for defining the positions of folders relative to the PARAM data-set.

(C) Any other activity where a temporary work-space is needed.

Good Practice

When work in a Sandbox is finished, and any files that are to be kept have been moved to a more secure location, delete all remaining files in the sandbox, with the exception of the file Sandbox.html.  If this is done then the next time the sandbox is needed, it'll be ready.
