Program SetUpMap

Program SetUpMap is run in a folder that contains reference data sets.  It generates a HTML list of the files together with individual HTML files, one for each reference data-set, and writes these files into the folders PARAM\HTML and PARAM\HTML\data_molecules.

Navigate to a folder that contains reference data, and issue the command SetUpMap followed by a filename of the data to be supplied to SetUpMap.  This file is created by running the utility program Files; this produces a file with the name "files.txt" If SetUpMap is run with the file files.txt it will produce a HTML file with the name files.html.  This name is not normally acceptable, however the name of the HTML file can be changed if files.txt is re-named, and SetUpMap run with the renamed file.  For example, if files.txt is re-named "Organic compounds.txt", and the command:

SetUpMap "Organic compounds"

is run, the resulting HTML file will be "Organic compounds.html"
