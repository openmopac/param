General problems with current semiempirical methods

All current (2018) semiempirical methods have a common fault, specifically that the parameter optimization was performed using only a small set of reference data.  These sets, although composed of a large number of data, was deficient for several reasons, including:

(A) Specific probative data were often missing.

(B) Specific phenomena, mainly intermolecular interactions, were also often missing.

(C) Many of the reference data are not accurate

(D) Less important, many diatomic interactions, e.g., potassium - zinc, were not represented.  In most such cases, no data were available, on others, the likelihood of such an interaction being of interest is small.

Approach to correcting faults  (A) and (B)

Fault (A)

 When a fault is detected that was caused by the lack of a specific type of data appropriate reference data should be added to the parameterization set, and a note of why it was added put in the parameterization set.  To prevent a re-occurrence of such faults, the parameterization sets should be carefully preserved.  Once a reference datum is added, it should not be removed until the reason for its addition has been addressed.

Fault (B)

All high-quality benchmark reference data sets for intermolecular interactions should be used in the training sets. With modern computers, the addition CPU cost is insignificant.

Fault (C)

Identifying inaccurate reference data is difficult.  Obviously, if the error in a datum is large, it would show up when surveys are done.  All large errors in reference data have already been identified and the appropriate action taken.  The real problem occurs when the error is not large, then the question arises regarding the origin of the difference between calculated and reference data. 

Experimentally-derived reference data should be regarded with skepticism, particularly when the system is unusual in any way, for example highly unstable or highly reactive.  Experimental thermochemical data on common systems such as ethylene and ammonia are highly reliable.  Experimental data that's older than 20-30 years should be regarded as being less accurate than modern data.

Modern benchmark computed reference data should be regarded as very accurate, and if a difference is found between the semiempirical results and the reference data, the origin of that difference can be attributed to faults in the semiempirical method.  A good, unresolved, example of this is provided by systems 6a and 6b in Risthaus and Grimme's S12L benchmark test.  When these two systems, also known as "BuNH4 CB6" and "PrNH4 CB6", were modeled using PM6-D3H4, the errors in interaction energies were -27.0 and -24.8 kcal.mol-1, respectively.  When a re-optimization of the PM6-D3H4 parameters was done using a reference data-set that included the S12L set, the errors for these systems decreased to -14.3 and -13.1 kcal.mol-1, respectively.  This error in re-optimized PM6-D3H4 can only be attributed to one or more still-unidentified errors in the semiempirical framework.
