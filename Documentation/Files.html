Program "Files"

Program Files is a utility program that is run in a folder that contains reference data.  It analyzes the contents of the folder and puts the summary into three files:

"files.out" that contains a summary of the reference data for use in the utilities And, Only, and All. Don't edit this file.  If a change needs to be made, edit the files in the reference data-set folder, and re-run Files. The ordered list of files in "files.out" begins three lines after the line containing the text "SEQUENCE OF COMPOUNDS IN PERIODIC TABLE ORDER" and, as the name suggests, the list is in order of the periodic table.  Rather than give a detailed definition, the easiest way to see this order is by examples, thus:

A fluorine cation comes before a fluorine atom, because the cation has one electron missing.
All fluorine systems come after all systems that contain only elements with lower atomic numbers.
Methane comes before ethane because ethane has more carbon atoms than methane.
Acetone comes before propanol because acetone has fewer hydrogen atoms.
m-dinitrobenzene comes before o-dinitrobenzene, because "m" comes before "o".
2,3-dimethyl phenol comes before 2,4-dimethyl phenol because "3" comes before "4".

"files.txt" used by the utility SetUpMap.

"bits.txt," an ordered list of the files in the folder.

Files can be run using either Windows Explorer or using the Command Prompt window.

Windows Explorer: Navigate to the folder that contains the folder of interest, then "drag and drop" the folder of interest on the Files icon.  Files will then open the folder of interest and produce the files described above.

Command Prompt: Navigate to the folder of interest and issue the command "files" from within that folder. Files will then produce the files described above.
