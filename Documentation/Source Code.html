Source Code

The Source Code folder contains a set of sub-folders. Several of these contain source code and Visual Studio solutions for utilities used in manipulating reference data and results from PARAM calculations.

One folder, "Bin and cmd" contains executables (binaries) and command scripts (<file>.cmd) that can be run. 

The folders "Scripts for Linux" and "Scripts for Mac" contain scripts for compiling MOPAC and PARAM on other platforms, for synchronizing the reference data sets across platforms, and one example data-set for PARAM.
