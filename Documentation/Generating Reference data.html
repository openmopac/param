Generating Reference Data

Reference data is represented by MOPAC data-sets, i.e., files that have the suffix ".mop" and their contents have the same format as normal MOPAC data-sets.  In fact, if needed, individual reference data files can be run using MOPAC.

Reference data file names

Use names that clearly indicate the chemical system. These names will only be used as labels for reference data files, they are not used in lists or tables.

Examples of reference data file names

Data-file name Description
[Hf(III)(H2O)6]3+ 2Ag.mop The 2Ag electronic state of hexaquo hafniumIII 
Lutetium, 2D(g) 6s(2)5d(1)6p(0).mop The ground state of the lutetium atom.
Ca(II)(Cp)2O2 (SEHPEA).mop From the CSD, bis(η5-Methylcyclopentadienyl)-(dimethoxyethane-O,O')-calcium
12 Hexafluorobenzenezene - benzene.mop Entry 12 of Hobza's X40 intermolecular interaction set

Keyword line

All normal MOPAC keywords are allowed, but several of these are ignored by PARAM.  The ignored keywords are: 1SCF, PRECISE, MECI, EXTERNAL, and all method keywords such as PM6-D3H4, PM7, etc. Keyword LET is changed to GEO-OK.  These changes are made to avoid conflicts with PARAM keywords.

First line of text

This should be a concise description of the system, typically the chemical name, e.g., "Methanol", "Water", "Sodium sulfate, anion", and "12 Hexafluorobenzenezene - benzene.mop"

Chemical names are used in forming tables, so they should be chosen with care, and properly typed, i.e., the first letter should normally be capitalized and appropriate punctuation used.  

Second line of text

This contains the reference data, weighting factors, and mnemonics for the source of the reference data, see keywords

Geometry

A normal MOPAC geometry is used for all systems except geometric references.  Geometric references are indicated by keywords "<>" and "<text>" and the geometry is defined in terms of these keywords.

Reference data set folders

Reference data can be assigned to different types such as data for ordinary compounds, data for electronic states, intermolecular interactions, etc.  For convenience, each reference data file should be stored in a folder that describes the type of system involved. For example, benzene would be stored in the folder "Data normal"  and the ground-state of hexaquo chromium(III), 4Ag, would be stored in "Data levels".  Entire sets of reference data can be assigned their own folder, thus each of the different intermolecular interaction reference data sets would be assigned its own folder.  These folders have names of the type "Data intermolecular interactions\S66 Intermolecular" and "Data intermolecular interactions\S66 Separated"  New folders can be added when necessary.
