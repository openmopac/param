Top-level folder: Analysis

Folder Analysis is used for quality control, statistical analysis, comparing the accuracies of methods, preparing tables for publication in journals and on the internet, etc. 

Default folders

To help in performing analyses of the various methods, sub-folders containing pre-computed comparisons of calculated and reference values for various quantities are constructed.  Each set of reference data files is given its own folder. For example, the S22 set, the set of all intermolecular interactions, and the set of all simple organic compounds, each has its own folder.  The name of the folder indicates which set it holds.  Within each folder are files listing the errors in various properties for various methods.  Individual properties are identified by their file suffixes, thus files giving heats of formation and heats of interaction have the suffix ".heats", Geometries have the suffix ".geos" Ionization Potentials:  ".ips" and Dipole moments ".dips" Each method also has its own name, thus all sets of systems calculated using PM6 would have the name PM6. So the hierarchy for naming is: Folder name = Set of reference data; File name = Semiempirical method; Suffix = property; Line in file = Individual reference datum.

These files are designed to be used by the analysis utilities.  They can be read using a simple editor such as Notepad, but they should not be edited.  If a change needs to be made, re-run PARAM to generate new files.  All the files used in analyses can be generated by running PARAM with an appropriately-named data-set, thus to generate files for PM6-D3H4X, construct a file PM6-D3H4X.dat and run that.

 Minimizing user-errors

To minimize the chance of introducing errors in an analysis, individual surveys should be automated as far as possible.  This type of automation is easily done using Windows command scripts, for example, constructing all the files of interaction energies for several different sets of species, S22, S66, etc, can be done using the following script named Construct_intermolecular_interactions.cmd:

REM
REM  Calculate intermolecular interaction energies for several methods for several sets of systems
REM
ECHO OFF
FOR  %%p IN (S22, S66, L7, S12L, "Water dimers", "D3H4 Ionic", X40, "All intermolecular interactions") DO (
cd %%p
FOR  %%q IN (PM8, PM7, PM6-D3H4, PM6-D3H4X, PM6-DH+, PM6-DH2, PM6-DH2X, PM6) DO (
echo Starting %%p %%q
CALL "%PARAM_start%\Source Code\Bin and cmd\PARAM_exe.exe" %%q
)
cd ../
)
rm */*.out
In this example the assumption is made that PM8 is a method being developed, and a set of updated parameters for PM8 are to be used.  If the updated PM8 parameters are deleted (edit PM8.dat to remove keyword "External") then standard PM6-D3H4 results would be obtained

Scripts of this type are written in the DOS language.  Rather than learn how to write in DOS, simply copy and edit an existing script.

Running an analysis is also done using a command script, in this case Analyze_intermolecular_interactions.cmd:

rm "%PARAM_start%\HTML Files\Stats_for_Heats_of_Formation.html" 2> nul
call "%PARAM_start%\Source Code\Bin and cmd\stats" %PARAM_start%\Analysis\S22\S22
call "%PARAM_start%\Source Code\Bin and cmd\stats" %PARAM_start%\Analysis\S66\S66
call "%PARAM_start%\Source Code\Bin and cmd\stats" %PARAM_start%\Analysis\S12L\S12L
call "%PARAM_start%\Source Code\Bin and cmd\stats" %PARAM_start%\Analysis\L7\L7
call "%PARAM_start%\Source Code\Bin and cmd\stats" "%PARAM_start%\Analysis\Water dimers\H2O Dimers"
call "%PARAM_start%\Source Code\Bin and cmd\stats" %PARAM_start%\Analysis\X40\X40
call "%PARAM_start%\Source Code\Bin and cmd\stats" "%PARAM_start%\Analysis\D3H4 Ionic\D3H4"
call "%PARAM_start%\Source Code\Bin and cmd\stats" "%PARAM_start%\Analysis\All intermolecular interactions\All"

By default, all analyses should be put into "PARAM\HTML Files" Other useful files are also deposited into this folder, with the most important of these being the JSmol files that allow individual reference data species to be easily examined.

Examples of Statistical Analyses

Construct and Analyze Intermolecular Interactions

(The commands mentioned here are in the top-level folder "Analysis")

Running Construct_intermolecular_interactions.cmd generates calculated heats of interaction for eight methods for seven sets of systems that involve non-covalent interactions.  This takes about two minutes to run.  After Construct_intermolecular_interactions.cmd has been run, run Analyze_intermolecular_interactions.cmd. This will make a single table summarizing the accuracies of the different methods, along with a set of tables supporting giving results for individual heats of interaction.  Analyze_intermolecular_interactions.cmd takes only a few seconds to run.

Construct and analyze survey organic

(The commands mentioned here are in the top-level folder "Analysis")

Construct_survey_organic.cmd takes a long time, typically several hours, to run.  The geometries of a set of over 4,700 chemical systems containing at least one of the elements H, C, N, O, F, Cl, Br, I, S, and P, are run using eight methods. Analyze_organic.cmd then runs a statistical analysis of  the results.  Because Construct_survey_organic.cmd takes so long, it should normally only be run when new systems are added to the set of reference data.  During parameter optimization, and when no new systems are being added, only the method being worked on needs to be re-run. This can be done by moving to "PARAM\Analysis\Survey organic" and running PARAM with the file PM8.dat.
