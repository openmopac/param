Utility program "Only"

This program selects all files in a reference data set folder that contain only one or more of the elements specified and no other elements.

How to run "Only"

Before Only is run, a file "files.out" must exist; this file is generated by the utility program Files.

Program "Only" is run at the command prompt.  Navigate to a folder that contains reference data, and issue the command "Only"  then follow the instructions. The list of files that contain one or more of the selected elements will be written to the file bits.txt
