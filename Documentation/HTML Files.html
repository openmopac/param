HTML files

This folder is unique in that its contents can routinely be deleted.  For this reason, the mirror-copy of "HTML files.html" is stored in folder "PARAM" and not in "PARAM\HTML Files" 

The folder "PARAM\HTML Files" is used to hold the results of analyses of the various methods, and HTML files that give information on the various reference data files that are present in the folder "Reference Data"

Editing individual files is discouraged because (a) the reason for the edit should be used in editing the scripts that generate the files in "HTML Files" and (b) when the files in this folder are re-written, any edits that had been made would be lost.

To re-generate the default set of files in "HTML files":

(A) Using Windows Explorer, navigate to the folder "HTML files"
(B) Delete all files. 
(C) To re-populate this folder:
      Navigate to "PARAM\Source Code\Bin and cmd"
      double-click on the command-file "Populate HTML files.cmd" This will run for a minute or two.
      If you have any other files, edit "Populate HTML files.cmd" to add the appropriate scripts.
