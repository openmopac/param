Reference Data

All reference data should be stored in sub-folders in this folder.

Individual reference data are expressed as MOPAC data-sets, with the reference data being defined on line 3.

When possible, the raw data used in constructing sets of reference data should be stored in a sub-folder in the reference data folder.  This is particularly important when benchmark sets of data are involved, because, if at some later date a question arises regarding the reference data, the original source material can be found quickly.

In recent years, a particularly important and valuable type of reference data, dealing with intermolecular interactions, has become available.
