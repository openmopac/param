Utility program "All"

This program selects all files in a reference data set folder.

How to run "All"

Before All is run, a file "files.out" must exist; this file is generated by the utility program Files.

Program "All" is run at the command prompt.  Navigate to a folder that contains reference data, and issue the command "All". The list of all reference data files will be written to the file bits.txt
