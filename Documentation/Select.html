Utility program "Select"

This program selects files in a reference data set folder that meet specified criteria and writes the file-names of the selected folder into a file named "bits.txt".  Program Files should be run before "select" is run; this makes a file named "files.out" that Select uses.

Although program Select can be run as a stand-alone utility is usually run in a command script that provides one of the criteria.  These scripts have the names "and", "only", "not", and "all".

Criteria for Select

Criterion 1:

Selection type. This option is placed on the command line after the word "select"

"AND" - All reference data files that contain any of the elements specified. For example, if oxygen is specified, "AND" would select all files that contain oxygen. If oxygen and nitrogen are specified, "AND" would select all files that contain oxygen or nitrogen

"ONLY" - All reference data files that contain all of the elements specified. For example, if hydrogen is specified, "ONLY" would select data such as hydrogen cation, hydrogen atom, and H2. If oxygen and hydrogen are specified, "ONLY" would select all files that contain oxygen or hydrogen, but not any other elements.

"NOT" - the opposite of "AND"

"ALL" - All reference data files.

Criterion 2:

Set of elements. This option is supplied after "select" starts and is not used if "ALL" is specified.

Either: Chemical symbols of the elements to be used in the selection. For simple organic compounds, use "H C N O", for organo-phosphorous compounds, use "C P"

Or: All elements in one of the methods in MOPAC, for example, "PM7", "PM6-D3H4", or "PM3".

After "select" is run, a file "bits.txt" is created in the current folder. This file contains the list of files defined by the two criteria.
