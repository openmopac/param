Folder "Bin and cmd"

"Bin and cmd" contains executables (binaries) and command scripts (<file>.cmd) that can be run.  Two types of executables are present:  One consists of utilities that are specific to parameter optimization, among these are MOPAC2016 and PARAM_exe, Files_program, select, SetUpMap, and Stats, the other consists of simple Linux commands for use on Windows platforms.  These include "vi", "grep", "ls", etc.

To convert files created on Linux and Mac platforms to Windows format, use the utility unix2dos.exe. If Linux or Mac platforms are used, copying and pasting onto the desktop a shortcut for unit2dos.exe can speed up the migration from these computers to the Windows platform. If that is done, then after the Unix-format files have been copied, they can be dragged-and-dropped onto the unix2dos icon, and the conversion will be done, overwriting the original Unix format.

A large number of command scripts are provided; some facilitate moving from one folder to another, other scripts act as assistants when more complicated operations need to be performed.
