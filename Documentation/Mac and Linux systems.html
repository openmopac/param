Mac and Linux systems

The PARAM structure is intended for use on a small computer, for example a normal office desktop computer.  Large parameter optimizations should not be run on such a machine because of the demand on resources could slow down other operations, such as using Microsoft Office, editing data-sets, reviewing results, etc.  Instead, large optimizations should be run on other computers, these include Mac and Linux platforms.

An efficient protocol to run parameter optimizations on Mac and Linux platforms is:

(A) Using utility files for Mac and Linux systems, install PARAM.

(B) Run a test to verify that PARAM is working.

(C) Prepare an optimization run on the Windows system, and verify that it works. As soon as you're satisfied that the job has started correctly on the windows system, kill that job.

(D) Copy the optimization data-set to the other platform. If desired, also copy EXTERNAL files to the other platform

(E) If desired, run "updatep" to update the PARAM program. If desired, run "updaterd" to update the reference data-sets.

(F) Run the parameter optimization job.

(G) If the results look good copy them back to the Widows platform, to a sandbox folder, convert the files to DOD format, and, after checking that they look good, move the converted files to their appropriate location. Using a sandbox helps to reduce the possibility of overwriting a good file with rubbish.
