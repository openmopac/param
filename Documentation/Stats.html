Program "Stats"

Program Stats performs statistical analyses of the results of surveys of various sets of systems run using various methods. The results are given as HTML files that are written to the folder "PARAM/HTML Files"

Two main types of analyses are performed. In one, a table is constructed showing the accuracies of various methods for various sets of systems, in the other, the average error per element for various methods for a set of systems is generated. 

Files can be run using either Windows Explorer or using the Command Prompt window.

Windows Explorer: Navigate to a folder that contains the results of a survey, and drag a Stats data-set set to the Stats icon. 

Command Prompt: Navigate to a folder that contains the results of a survey, and issue the command "Stats <Stats data-set>" where "<Stats data-set>" is the data-set that holds information on what Stats is to do.

Stats Input

Input consists of a file containing a set of keywords, one per line, that define different quantities.  All keywords are case-insensitive, but must be positioned at the beginning of a line, without leading spaces.

Keywords

Elements: Two very different analyses are performed depending on whether keyword ELEMENTS is present or not present.

When keyword ELEMENTS is present, then optional restrictions can be specified, and only those systems that comply with the restrictions will be selected for the statistical analysis.  In addition, if a previous statistical analysis is present in the output folder, then the results of the current analysis will be added, as a new line of statistics, to that analysis.  This option allows a table giving average errors for different methods for different sets of data-files to be constructed by running Stats repeatedly, each time using a different set of reference data but with everything else being the same. Two modes are supported; Stats can be run in several different folders, i.e., folders that contain results for different sets of systems, or Stats is run in the same folder, but with different set of restrictions on the set of atoms allowed.  In both cases the output file has to have the same name. Because of the increased probability of making a typographic error, a useful strategy is to construct a data-set, and make sure that it works correctly, then constructs a command script that deleted the existing HTML table then runs each of the different analyses in turn.  Running that script takes little time, and a useful table can be generated quickly and easily.

When keyword ELEMENTS is not present, all systems will be selected, and an analysis giving the average error per element for each method will be done.

When ELEMENTS is selected, and no restrictions are specified, all systems are selected.  Three types of restrictions are defined, these are:

MUST=(elements): List of elements that must be present in each system.  For example, ELEMENTS: MUST=(C H N O) would select all systems that contain the elements carbon, hydrogen, oxygen, and nitrogen.  So glycine would be selected, but ethanol would not.

AND=(elements): List of elements that can be present.  For example, ELEMENTS: AND=(F, Cl, Br, I) MUST=(C) would select all the halogenated organic compounds.

NOT=(elements): List of elements that must not be present. For example, ELEMENTS: NOT=(C) would select all the inorganic compounds.

Heading: Defines the heading of the web-page. If not present, a default heading will be used.

Methods: Each survey data-set should be names with the method used, e.g., the data-set for a survey using the PM6-D3H4 method should be named PM6-D3H4.dat.   Then the keyword METHODS should be followed by a list of methods, e.g.:
Methods: PM8 PM7 PM6, PM6-D3H4X PM3 MNDO AM1 RM1 PM6-D3H4 PM6-DH2X PM6-DH+ PM6-DH2

Output: Define the path, the filename, or both the path and filename, for the results.   Quotation marks are allowed, but are not necessary. Examples: OUTPUT: ..\..\HTML files\Statistics for Intermolecular interactions.html, OUTPUT: C:\..\..\..\HTML files\, OUTPUT: Statistics for Intermolecular interactions.html  The second of these options
