Parameter Optimization

All parameter optimizations should be run from within folders in "%PARAM_Start%/Parameter Optimization" PARAM.zip is distributed with three examples of parameter optimization, CHNOXSP, Simple, and Elements. Two other folders are present. One is a standard Sandbox folder. The other, Folder "Sets", contains files each of which represents a specific collection of reference data.   Most collections are for individual elements, one, "Stand-alone Core.txt" is a collection of reference data designed for forming the core of a new method.  It contains representative systems for each of the elements H, C, N, O, F, P, S, Cl, Br, and I, plus a set of systems that represent intermolecular interactions.

Folder CHNOXSP

Complete data-set CHNOXSP.dat 
*
*  Optimize all parameters for H, C, N, O, F, Cl, Br, and I, and all intermolecular interactions, using the method PM8
*  
*
*     Keywords used
*
* SET:        Define the sets of files that contains lists of compounds to be used.
* REF:        Define all the folders that contain reference data for systems defined by SET. 
*
set="core.txt" &
ref= &
"../../reference data/Data Intermolecular interactions/S22 Intermolecular"; &
"../../reference data/Data Intermolecular interactions/S22 Separated"; &
"../../reference data/Data Intermolecular interactions/S66 Intermolecular"; &
"../../reference data/Data Intermolecular interactions/S66 Separated"; &
"../../reference data/Data Intermolecular interactions/L7 Intermolecular"; &
"../../reference data/Data Intermolecular interactions/L7 Separated"; &
"../../reference data/Data Intermolecular interactions/S12L Intermolecular"; &
"../../reference data/Data Intermolecular interactions/X40 Separated"; &
"../../reference data/Data Intermolecular interactions/X40 intermolecular"; &
"../../reference data/Data Intermolecular interactions/Water dimers all"; &
"../../reference data/Data Intermolecular interactions/D3H4 Ionic Intermolecular"; &
"../../reference data/Data Intermolecular interactions/D3H4 Ionic Separated"; &
"../../reference data/Data normal"; &
"../../reference data/Data levels"; &
"../../reference data/Data erratic" &
*
*  Use the PM6-D3H4 method as the starting point
*
   cycles=100  
*
* No more continuation symbols, "&", so now define the parameters to be optimized
*
* PAR7, PAR8, and PAR9 are parameters for Grimme's "D3" method 
*
PAR7  0.2  1.3  = s3  in subroutine DFTD3
PAR8 12.0 15.0  = alp in subroutine DFTD3
PAR9  0.5  2.0  = rs6 in subroutine DFTD3
*
*  Some parameters need non-standard lower and upper bounds
*
alpb_h H 0.9 5
xfac_c H 0.1 5 
xfac_n H 0.1 5       
xfac_o H 0.1 5       
FN21 N 0.5 5
FN21 C 0.5 5
HSP C 0.5 5
xfac_O O 0.1 5 
xfac_F F 0.1 5 
*
* Finally, the set of all other parameters
*
(H C N O F Cl Br I S P)(All)  
*
*  And end the parameter list with the word "end"
*          
end

This is an example of a starting step for a new method.  As this would be a large project the data set is unusually detailed, with many comments and with the data nicely formatted.  Comments are essential here, because after the job is run successfully, it might be months before this stage in method development is re-visited.  Nice formatting is also important.  If the various files and folders are typed as one continuous line, then finding errors is difficult, as is modifying the data-set to add or delete individual files and folders.

Details of data set

The set of reference data used is defined by 'set="../sets/Stand-alone core.txt"' and all the individual reference data files can be found in the folders defined by PARAM keyword REF.  

Keyword REFERENCES is present, but is only a placeholder for future jobs that involve surveys.

PAR7, PAR8, and PAR9 are global parameters, the ALPB and XFAC are diatomic parameters, the remaining explicit parameters are atomic.  The presence of the line "(H C N O F Cl Br I S P)(All)" instructs PARAM to add in all other parameters for the core elements.

A method keyword PM8 is unnecessary, because PM8 is the default method. 

Keyword CYCLES is set to 100.
