Generating an updated FORTRAN Parameter module

Before any parameterization is done the default PM8 method would produce exactly the same results as the PM6-D3H4 method.  Each successful parameterization would produce a file that could be read in to new PARAM optimizations using the EXTERNAL option.  An alternative to using the EXTERNAL option would be to update the PM8 module.  If this were to be done, then the resulting PARAM and MOPAC programs would be able to run the new PM8 method without using keyword EXTERNAL.

After the PM8 module is updated the PM8 method will no longer produce PM6-D3H4 results, instead it will produce PM8 results, i.e., PM8 will be a new method.  Such an update should not be performed until after enough tests and statistical analyses have been performed that a high degree of confidence exists that the change is an improvement.  For example, if the objective of the project is to produce a new, general method, one milestone would be to achieve a significant improvement in the performance of the core elements H, C, N, O, F, P, S, Cl, Br, and I in predicting properties of interest, e.g. heats of formation, geometries, dipole moments, ionization potentials, intermolecular interaction energies and geometries, etc.  After such a milestone is achieved, the PM8 module could be updated, and work then started on the next step.  This process would be repeated as necessary, i.e., work is done, a milestone achieved, PM8 is updated, and work started on the next step.

Whenever PM8 is updated, the previous PM8 module, all PARAM data-sets, and associated reference data, etc., should be archived carefully. There is a 100% probability that at least one update will need to be re-visited, and having access to an archive that would allow work to be resumed on an old version of PM8 is absolutely essential.

Updating PM8

To perform an update, create a PARAM data-set, update.dat.  This data set should contain two keywords EXTERNAL and DEP. When update.dat is run using PARAM a new file "parameters_for_PM8_C.F90" is generated.

Make a backup copy of the existing MOPAC source-code file "parameters_for_PM8_C.F90" The backup should contain a note describing the version of "parameters_for_PM8_C.F90" so that if anything goes wrong, the old file can be restored.  Then overwrite "parameters_for_PM8_C.F90" in the MOPAC source code with the new copy.  Re-compile both MOPAC and PARAM.  Run tests to verify that the update was successful.
