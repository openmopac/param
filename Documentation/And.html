Utility program "And"

This program selects all files in a reference data set folder that satisfy the criteria regarding the elements in each system. Criteria can be specified two ways:

(A) By method: If a method, e.g. AM1, is given, all data-sets that contain at least one element that has been parameterized for that method will be selected.

(B) By element(s): If one or more elements, e.g., C, or C and F, are selected then all systems that contain at least one of those elements will be selected.

How to run "And"

Before And is run, a file "files.out" must exist; this file is generated by the utility program Files.

Program "And" is run at the command prompt.  Navigate to a folder that contains reference data, and issue the command "And"  then follow the instructions. The list of files that contain one or more of the selected elements will be written to the file bits.txt
