A simple parameter optimization

In its simplest form, a parameter optimization job requires three types of data: A list of names of reference data files, the location of the folder where those files are stored, and a list of parameters to be optimized. An example of such a data-set is shown in the box
A simple parameter optimization data-set   
set="../sets/Stand-alone core.txt" &
ref="../../reference data/Data normal"
(H C N O)(All)
 
below.

Two PARAM keywords are used. The location of the file that holds the names of the reference data files is specified by SET, and the location of the folder where the reference data files are stored is specified by REF. All keywords must be on the same line, but for convenience the symbol "&" is provided.  This symbol means that the text in the following line should be concatenated to the current line.

The third line of the data-set defines the set of parameters to be optimized.
